# CPP Module 09

CPP Module 09 is part of the C++ modules in the 42 curriculum and focuses on using standard containers and algorithms to solve practical problems. The project involves implementing applications such as a Bitcoin exchange rate calculator, a Reverse Polish Notation (RPN) evaluator, and a hybrid sorting algorithm (Ford-johnson algorithm) using containers like `std::map`, `std::stack`, and `std::vector`. It strengthens understanding of data structures, algorithm design, parsing, and efficient data processing in C++.

**Technologies:** C++, STL, std::map, std::stack, std::vector, Algorithms, Makefile, Git.
